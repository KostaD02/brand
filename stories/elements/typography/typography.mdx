# Typography

Element-level type defaults. Headings, paragraphs and small text apply to bare tags and
need no classes; the section heading, mono, list and header anchor are opt-in classes.
They ship in the `elements` layer, separately from the reset.

## Headings

`h1` through `h6` use the primary family at semibold with a tight line height. Sizes are
fluid: `h1` and `h2` each have their own `clamp()`, and `h3` through `h6` share one.

<Canvas of={TypographyStories.Headings} />

> Heading sizes come from `--kd-font-size-fluid-*`, not the static scale, so they respond
> to viewport width without a media query. Reach for `kd-fs-*` only when you need a fixed
> size.

## Paragraphs and small text

`p` has no margin at all, which is deliberate: spacing is owned by the layout, not the
element. `small` and `kd-small` drop to the muted colour.

<Canvas of={TypographyStories.Paragraph} />

> Because `p` has no margin, a run of paragraphs collapses into a solid block. Use
> `kd-mb-*` or a flex column with `kd-gap-*` for rhythm.

## Section heading

`kd-heading` is the page-section treatment: a fluid heading followed by a rule that fills
the remaining width, capped at 300px.

<Canvas of={TypographyStories.SectionHeading} />

> Two things to know. The rule uses `--kd-bg-elevated`, a surface token rather than a line
> token, so its contrast against the page is around 1.1:1 and it reads as very faint by
> design. And the heading is `white-space: nowrap` with no overflow guard, so long text
> pushes past narrow viewports rather than wrapping; `kd-heading--wrap` is the release
> valve for that.

## Section heading variations

Three modifiers, each for a different problem. `kd-heading--bare` hides the `::after` rule,
which is what you want for a centred section title where a rule hanging off one side would
look lopsided. `kd-heading--center` handles the centring itself, since the block is a flex
row. `kd-heading--wrap` swaps the default `nowrap` for `normal`, so a long title breaks
onto a second line instead of running off a narrow viewport.

<Canvas of={TypographyStories.SectionHeadingVariations} />

> The third heading in that canvas is the unmodified default at the same width, so you can
> see what `kd-heading--wrap` is fixing.

## Sizing the section heading

Five custom properties are declared on the block: `--kd-heading-font-size`,
`--kd-heading-margin`, `--kd-heading-rule-width`, `--kd-heading-rule-gap` and
`--kd-heading-rule-color`. Reassign them inline for a one-off.

<Canvas of={TypographyStories.SectionHeadingCustom} />

> `--kd-heading-font-size` exists so a single instance can shrink without a literal
> `font-size` in the style attribute. A literal wins outright and leaves the heading
> disconnected from the fluid token; the custom property keeps it inside the system, so
> the rest of the block still behaves.

## Monospace

`kd-mono` switches to the mono family and enables tabular figures, so columns of numbers
align.

<Canvas of={TypographyStories.Mono} />

## List

`kd-list` replaces the marker with an accent triangle. It is element-qualified as
`ul.kd-list`, so it applies to unordered lists only.

<Canvas of={TypographyStories.List} />

> An `<ol class="kd-list">` gets nothing, because the selector requires `ul`. Use a `ul`
> or style the ordered list yourself.

## List columns

The list is a grid, and `--kd-list-columns` is its `grid-template-columns`. It defaults to
`1fr`, so a plain `kd-list` is a single column. Set it to `repeat(2, minmax(100px, 200px))`
for the two column skills list: each column is at least 100px and stops growing at 200px,
which keeps short entries from stretching into a sparse row. `--kd-list-gap-x` sets the gap
between those columns and defaults to `0.625rem`.

<Canvas of={TypographyStories.ListColumns} />

> Both properties are new. Earlier the list declared `display: grid` and a column gap but
> never emitted `grid-template-columns`, so it could only ever render one column and the
> column gap had nothing to sit between. Any markup written against the old behaviour is
> unaffected, because the default is still one column.

## Plain list

`kd-list-plain` is the reset, not a style: margin `0`, padding `0`, `list-style: none`, and
nothing else. Reach for it when the list is a layout row rather than prose, a tag row or a
nav, and compose the layout from utilities.

<Canvas of={TypographyStories.ListPlain} />

> It sits in the `elements` layer rather than the `utilities` layer on purpose. Both are
> single-class selectors, so the tie is broken by source order, and utilities come last.
> That means `kd-m-*`, `kd-mt-*` and `kd-p-*` still beat the reset's zeroes, as the second
> row above does with `kd-mt-4`. Move it into `utilities` and whether a margin applies would
> depend on which partial happened to be emitted last.

## Header anchor

`kd-header-anchor` is for permalinks on headings. It inherits the heading colour, drops
the sweeping underline that every other anchor gets, and tints to accent on hover.
