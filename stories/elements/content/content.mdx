# Content

Element defaults for written content: quotes, rules, figures and code. Like typography
these apply to bare tags and ship in the `elements` layer. The `kd-prose` class at the
bottom of this page is the opt-in wrapper for a full article.

## Blockquote

An accent left border with the corners rounded on the closing side only.

<Canvas of={ContentStories.Blockquote} />

## Rule

`hr` is drawn as a top border rather than a height, so it stays exactly one border width
regardless of zoom.

<Canvas of={ContentStories.Rule} />

## Inline code

`code` uses the mono family with the code foreground colour on an elevated background.
Both are theme roles, so it recolours in light mode.

<Canvas of={ContentStories.InlineCode} />

## Code block

`pre` carries the code background and an accent bar down the left edge, drawn as a
pseudo-element. A `code` inside a `pre` drops the inline padding and background so the
two do not double up.

<Canvas of={ContentStories.CodeBlock} />

> `pre` scrolls horizontally rather than wrapping. Give it a bounded width, or it will
> stretch its container.

## Figure

`figure` gets vertical margin and `figcaption` is muted and one size down.

<Canvas of={ContentStories.Figure} />

## The prose class

`kd-prose` is for a written page rather than an application screen. It raises `p` and
`li` to the medium size, steps the headings down so `h1` inside an article does not
compete with the page title, and constrains images.

<Canvas of={ContentStories.Prose} />

> Outside `kd-prose` paragraphs still have no margin of their own. An application screen
> sets its own rhythm with a flex column and `kd-gap-*`, or the paragraphs run together.

Pair it with `kd-measure-*` from [Container](?path=/docs/layout-container--docs) to cap
the line length.

## Vertical rhythm

The reset sets `p { margin: 0 }` because spacing a page is the container's job, and for a
written page `kd-prose` is that container. It gives `p` and `ol` a bottom margin of one
space step, so a multi paragraph article reads correctly with no wrapper doing the
spacing.

<Canvas of={ContentStories.ProseRhythm} />

## Lists in prose

A `ul` that never passed through an author, the kind a markdown pipeline emits, picks up
the same accent triangle as `ul.kd-list` through `::marker`. The rule is written as
`ul:not(.kd-list)` on purpose: `kd-list` draws its marker with a pseudo-element, so
without the guard an authored list would carry both at once and every item would show two
markers.

<Canvas of={ContentStories.ProseLists} />

## Overflow

Grid and flex items default to `min-width: auto`, which means their minimum size is the
width of their content, so one long line in a `pre` widens the track and pushes the
layout out sideways. `kd-prose` sets `min-width: 0` on itself and caps `pre` and
`kd-table-scroll` at `100%`, which holds the code block inside its column and lets it
scroll on its own.

<Canvas of={ContentStories.ProseOverflow} />

> This is a container-level fix, so it works at any width. A viewport-relative
> `max-width` on `pre` looks correct on the page it was measured against and nowhere
> else.
