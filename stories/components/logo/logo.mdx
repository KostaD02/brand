# Logo

The hexagonal K, drawn entirely in CSS. Five elements, no image file, and it follows
the theme because its colour is a token.

## Example

The mark is one letter plus three sides. Each `kd-logo__side` is a box as wide as the logo
that draws a bar down its left edge with `::before` and another down its right edge with
`::after`. The first side sits flat, the second is rotated 60 degrees, the third by -60, so
the six bars close into a hexagon around the initial.

<Canvas of={LogoStories.Example} />

> The sides must be `<i>` and the initial must be a different tag. The rotation is selected
> with `:nth-of-type`, so the three sides have to be the first three `<i>` elements in the
> block. Anything else inside the logo that renders as an `<i>` shifts the count and a side
> loses its angle.

The initial is a letterform rather than content, so label the whole mark with `role="img"`
and an `aria-label` instead of letting a screen reader announce a stray K.

## Sizing

`--kd-logo-width` is the only value you normally set. The height is 7/6 of it and each side
is 17/30 of it tall, which is what gives every bar its length, so the proportions hold at
any width. Bar thickness is the exception: `--kd-logo-bar` is a flat 4px and does not
scale, so move it with the width when you go far from the default.

<Canvas of={LogoStories.Sizes} />

## Colour

`--kd-logo-color` paints the initial and all six bars from one declaration, and defaults to
`var(--kd-accent)`. Reassign it on the logo rather than reassigning the accent when only
the mark should differ.

<Canvas of={LogoStories.Colour} />

## As a link

The block already zeroes its own `::after`, which is the sliding underline the elements
layer adds to every bare `<a>`. That means the logo can be the anchor itself with nothing
to undo. Give it an `aria-label`; a single K is not an accessible name.

## Customising

`--kd-logo-width`, `--kd-logo-bar` and `--kd-logo-color` are declared on the block, so all
three can be reassigned inline for a one-off. The initial's size is not among them: it
reads `--kd-font-size-lg` directly, so a logo much bigger than the default wants a
`font-size` on `kd-logo__initial` too.
