# Empty

The screen a route falls back to when there is nothing to render: a 404, a deleted record,
a search that found no rows. It is a centred flex column with two named elements, and it
carries no height of its own, so it sits in whatever box you give it.

## Example

`kd-empty__code` is the status line, accent coloured and pinned at `--kd-font-size-xl`.
`kd-empty__title` is the message; it sets spacing and line height only, so the heading
level you pick decides its size. End with a `kd-btn` so the page is not a dead end: the
button is usually an anchor here, and `kd-btn` already cancels the sliding underline the
elements layer puts on bare links.

## Typewriter title

`kd-typewriter` types the line out by animating its width in discrete steps, with a caret
blinking on the trailing border. Set `--kd-typewriter-steps` to the character count of the
string so each step lands on exactly one letter; leave it at the default 30 for a shorter
line and the steps land mid glyph, which reads as a stutter rather than as typing.

<Canvas of={EmptyStories.Typewriter} />

> The effect depends on `overflow: hidden` and `white-space: nowrap`, so the line cannot
> wrap. Keep it to a few words, or it runs off the side of a narrow screen instead of
> breaking.

## Full height

An empty state that centres inside a short box looks like a mistake, so give it the
viewport: `kd-section` for the padding, `kd-h-viewport` for the height. That utility is
`calc(100dvh - var(--kd-scroll-offset))`, and `--kd-scroll-offset` is
`--kd-navbar-height` plus one space step, the same number the reset already uses for
`scroll-padding-top`. `kd-h-screen` is a flat `100dvh`, which on any page with fixed
chrome is one header too tall: the content centres below the middle and the page grows a
scrollbar it has no content for.

<Canvas of={EmptyStories.FullHeight} />

> The demo pins a height inline so this page stays short, and the strip above stands in
> for the fixed header. On a real page nothing sets a height at all; the class measures
> the viewport itself.

## Customising

`.kd-empty` declares no custom properties of its own: it is spacing and alignment on top
of tokens, and the knobs belong to the pieces it composes with.
`--kd-typewriter-steps` and `--kd-typewriter-duration` are declared on `kd-typewriter`, so
reassign them on the title element itself. `--kd-scroll-offset` is derived on `:root` from
`--kd-navbar-height`, so a project sets that one number and the height utility and the
scroll padding both follow.
